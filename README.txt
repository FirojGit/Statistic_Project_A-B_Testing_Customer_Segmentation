# A/B Testing & Customer Segmentation

## 📌 Overview
Statistical hypothesis testing and clustering for customer segmentation.

## 🗂 Dataset
- Kaggle A/B Testing Dataset

## ⚙️ Workflow
1. Test setup & exploration
2. Hypothesis testing (t-test, chi-square)
3. Confidence intervals & effect size
4. Customer segmentation (clustering)

## 📊 Deliverables
- Jupyter notebook
- Statistical summary
- Business recommendations

## 🛠 Tech Stack
Python, Pandas, NumPy, SciPy, Matplotlib, Seaborn
